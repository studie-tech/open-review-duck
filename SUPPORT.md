# Support policy

Use GitHub Issues for reproducible bugs and focused feature requests. Use GitHub
Discussions for installation, configuration, and general usage questions.
Include the ReviewDuck version, deployment mode, provider, browser, relevant
redacted logs, and reproduction steps. Community support is best-effort and
does not include an uptime or response-time commitment.

Security reports belong in the private channel described in `SECURITY.md`.
Questions about commercial licensing should be sent to the repository owner
through the contact details on the GitHub profile.
